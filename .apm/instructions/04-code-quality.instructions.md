## Code quality

- Read files in full before broad edits, audits, or changing unread files; do not rely on search snippets
- Ask before removing intentional behavior
- No shims unless asked

## Monorepos

When working in a monorepo:

- Prefer project-local configuration and follow project-local `AGENTS.md` and `.agents/skills/`
- Never edit or delete the root `README.md`
