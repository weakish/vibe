How small can a bar→psi CLI get?

One conversion, four toolchains. Zig and Teal→clx fight for the small binary; Goblin is the heavy Go baseline; Reason adds OCaml native and a Melange path.

The bake-off

psi = bar × 14.503773773022 (from 100000 Pa / 6894.757293168 Pa). Each port prints the same line shape the calculator uses above. The point of the repo is not the physics — it is how much executable you drag along to do almost nothing.

Linux x86_64

Measured 2026-07-17 on commit 5f589d7 via ./build-all.sh (zig 0.16.0, clx 0.1.0, goblin 14a7a3faa9da, Go 1.22.2). Reason native and Melange→Deno sizes are not in this snapshot (those ports landed later); re-run ./build-all.sh for current numbers.

Language Bytes Approx vs Zig Linking
Zig 160,888 ~157 KB 1.00× static
Teal→Lua (clx) 186,776 ~182 KB 1.16× dynamic (libstdc++, libm, libc)
Go (goblin, stripped) 2,095,288 ~2.0 MB 13.02× dynamic (libc)

macOS Intel

Same commit and script (Go 1.26.5). Absolute sizes differ; compare within a platform.

Language Bytes Approx vs Zig Linking
Zig 136,284 ~133 KB 1.00× static
Teal→Lua (clx) 302,144 ~295 KB 2.22× dynamic (libc++, libSystem)
Go (goblin, stripped) 2,512,824 ~2.45 MB 18.44× dynamic (libc)

Takeaways

  • On Linux, clx and Zig are close; Zig is ~14% smaller and fully static (clx’s on-disk size excludes libstdc++/libm).
  • On macOS Intel the gap widens (~2.2×) but both still dwarf Go.
  • Goblin/Go is an order of magnitude larger even stripped — runtime + GC.

Ports

Zig, Lua, Reason, and Goblin take argv. Reason ships ocamlopt native and Melange→deno compile. The widget on this page reuses the same Melange Convert module as the Deno CLI — typed Reason, plain DOM.

Build the calculator with site/build.sh, then serve site/ over HTTP (ES modules). Re-run ./build-all.sh in the repo to refresh size numbers on your machine.
